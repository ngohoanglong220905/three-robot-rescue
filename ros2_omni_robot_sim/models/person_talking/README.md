# Talking human actors

Original `talk_a.dae`, `talk_b.dae` from Open Robotics'
[Gazebo Classic](https://github.com/gazebosim/gazebo-classic/tree/b22c6e15e52299865b31093b8feebc9ca19e26e8/media/models).
Copyright Open Source Robotics Foundation; upstream Apache license retained in
`LICENSE`. Download URLs and SHA-256 are in `sources.json`.

Modified files `talk_a_inplace.dae`, `talk_b_inplace.dae` are generated by
`scripts/generate_talking_people.py`: select about 24 seconds, sample at 12 Hz,
fix hip translation and orientation, blend the loop ending into the first frame,
and compute the foot-height offset. Local head, torso and arm animations remain.
`loops.json` supplies generated duration/height to the world generator. No files
are downloaded when Gazebo starts. Original files remain for reproducibility.

SDF uses stationary trajectories with `interpolate_x=false` so gestures advance
with simulation time instead of distance travelled. See
[Gazebo Fortress actors](https://gazebosim.org/docs/fortress/actors/).
Actors provide RGB/depth/GPU-LiDAR geometry. Invisible fixed torso collision
proxies add physical contact; they are not supplied to camera perception or
stored in the empty occupancy map. There is no speech audio.
